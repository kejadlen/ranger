---
name: ranger
description: Use when managing tasks with the ranger CLI — creating backlogs, tracking work, picking up tasks, prioritizing, or following the ranger PM workflow in any project
---

Run `ranger __internal skill` and follow the guide it prints. The guide comes
from the installed ranger binary, so it describes the commands available in
that version.

If the command fails, the installed ranger predates the guide. Use `ranger
--help` and `ranger COMMAND --help`, and treat every change as tracked work:
create a task before starting, and mark it done only after the change is
committed.
